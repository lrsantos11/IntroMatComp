# Ementa de MAT4642 - Introdução à Matemática Computacional

- Representação de números em computador.
- Aritmética de ponto-flutuante e erros de
arredondamento. 
- Técnicas de elaboração, estrutura de dados e implementação de programas em
linguagem de alto nível. 
- Elaboração e implementação de algoritmos para solução de problemas de
matemática computacional. 
- Visualização de dados e de gráficos de funções. 
- Uso de ferramentas de computação simbólica. Uso de bibliotecas para solução de problemas matemáticos e simulação.
