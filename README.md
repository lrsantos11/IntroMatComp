# MAT4642 - Introdução à Matemática Computacional


Bem-vindos à disciplina MAT4642 da [UFSC/Blumenau](blumenau.ufsc.br). Este é um curso para introdução à matemática computacional, com foco em métodos numéricos. O curso é oferecido no para alunos da Licenciatura em Matemática da  erá ministrado pelo professor Luiz-Rafael Santos.

## Instalação de programas necessários 
Usaremos os seguintes softwares (**open source**):
- [Linguagem Julia](www.julialang.org)
- [Notebooks Pluto](https://github.com/fonsp/Pluto.jl)

Por favor,  siga [as instruções ](https://www.youtube.com/playlist?list=PLIFgJAiAvzyFlCskAMgMFEtRWIY5OaNt_) para instalar Julia e Pluto.
